### 1. Objetivo y Alcance

Verificar operador de neteo hedge para cuenta en liquidacion:

- Entrada: positions[acct][contract] = [long: 0..MaxQty, short: 0..MaxQty]
- Operador: NetPosition(lg, sh) = IF lg-sh >=0 THEN [lg-sh, 0] ELSE [0, sh-lg]
- Alcance: Solo aritmetica de cantidades. NO incluye: entryPrice, PnL, fees, funding, Cross/Isolated, BankruptcyPrice.

### 3. Definición Formal de Invariantes

NET004_NetConservation
  \A lg,sh: NetPosition(lg,sh).long - NetPosition(lg,sh).short = lg - sh
  => L'-S' = L-S

NET005_DeterministicFunction
  (lg1=lg2 /\ sh1=sh2) => NetPosition igual. Tautologica, trazabilidad.

NET006_GrossNeverIncreases [NUEVA SUSTANTIVA]
  phase="DONE" => \A c:
    LET base=baseline[liq][c], cur=pos[liq][c]
    IN cur.long+cur.short <= base.long+base.short
  Formaliza |L'-S'| <= L+S. Reduccion de exposicion bruta.

NET006b_AbsNetEqualsGrossPost [NUEVA]
  phase="DONE" => \A c: cur.long+cur.short = |cur.long-cur.short|
  Post-netting gross = |net|

NET007_OtherAccountsUnchanged [NUEVA SUSTANTIVA]
  \A acct != liq: \A c: pos[acct][c] = baseline[acct][c]
